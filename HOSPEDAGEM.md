# 🌐 Hospedagem - Jogue em Qualquer Lugar

Se quer jogar com amigos de outras cidades, hospede o jogo em alguma plataforma!

## Opções Gratuitas Recomendadas

### 1. **Railway.app** (MAIS FÁCIL ⭐)

**Passo a Passo:**

1. Acesse: https://railway.app
2. Clique em "Start a New Project"
3. Escolha "Deploy from GitHub"
4. Autorize o GitHub
5. Selecione seu repositório
6. Clique "Deploy"
7. Pronto! Seu jogo está online!

**URL do seu jogo:** https://seu-projeto.up.railway.app

---

### 2. **Heroku** (Clássico)

**Passo a Passo:**

1. Crie conta: https://heroku.com
2. Baixe o Heroku CLI
3. Abra o terminal na pasta do projeto
4. Execute:

```bash
heroku login
heroku create meu-fogo-de-proposito
git push heroku main
```

5. Seu jogo está online em: https://meu-fogo-de-proposito.herokuapp.com

---

### 3. **Replit** (Mais Visual)

1. Acesse: https://replit.com
2. Clique em "Create Repl"
3. Escolha "Node.js"
4. Copie os arquivos do projeto
5. Clique "Run"
6. Compartilhe o link com amigos!
