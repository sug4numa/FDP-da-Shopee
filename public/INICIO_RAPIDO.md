# 🚀 Início Rápido - Fogo de Proposito Online

## 5 Passos para Jogar

### 1️⃣ Baixe e Abra a Pasta
```bash
cd caminho-da-pasta-do-jogo
```

### 2️⃣ Instale as Dependências
```bash
npm install
```

### 3️⃣ Inicie o Servidor
```bash
npm start
```

### 4️⃣ Abra o Jogo
- Abra seu navegador
- Acesse: **http://localhost:3000**

### 5️⃣ Convide Amigos
- Crie uma sala
- Copie o código
- Compartilhe!

---

## Fluxo do Jogo Rápido

1. Digite seu nome e **"Criar Sala"** ✅
2. Copie o código e envie para seus amigos 📱
3. Espere todos entrarem 👥
4. Clique **"Iniciar Jogo"** 🎮
5. Complete as propostas e ganhe pontos! 🎉

---

## Problemas Comuns

| Problema | Solução |
|----------|---------|
| "Cannot find module" | Execute: `npm install` |
| Porta 3000 ocupada | Execute: `PORT=3001 npm start` |
| Amigos não conseguem conectar | Use seu IP |

Divirta-se! 🎉
